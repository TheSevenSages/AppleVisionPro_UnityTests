## Accomplishments

###### *What did I actually complete?*

* RequestDeviceLink
  * Server method that allows clients of type HOST to send a request to the server to establish a link with an unlinked guest device.
* Disconnected devices automatically have their link severed if they had one.
* Set up NetworkTest scene to actually send link requests to the server when a guest is selected from the guest list.

## Challenges & Blockers

###### *What problems did I run into? Even small frustrations are worth noting.*

* UInt32's are currently being used as the IDs for devices on the SageXR server, this could cause issues passing numbers back and forth between json and C# since some versions of Json (JavaScript apparently) don't support numbers that high. 
  * I'm going to replace them with string representations of the number.
* On the NetworkTest scene I refreshed the guest list during OnStart which was before the server could finish initializing the connection. This caused errors to be returned.
  * Now all the functions that call methods on the server wait for init to be finished first.

## Learnings & Key Takeaways

###### *What did I learn today? Could be a new skill, trick, process, or even a fun fact!*

* Interestingly Json may not be able to store numbers that are too high. This makes sense but I just never considered it...

## Goals for Today

###### *What are the most critical tasks I plan to tackle today?*

1. Allow clients to send messages over their link, then begin building out the Unity-level abstraction layers to the network.
2. When clients disconnect from the server their links should be severed automatically if they have any.

## Accomplishments

###### *What did I actually complete?*

* Allow clients to get the status of their link by querying the server using the "RequestServerData" method with the parameter "LINK".
  * This returns a Json object with data that tells the client if its linked to anybody and if so who that somebody is.
* Clients can now send messages back and forth!

## Challenges & Blockers

###### *What problems did I run into? Even small frustrations are worth noting.*

* I don't want clients to need to wait for a response from the server after sending a message to it's link because that could take a long time, but then how do we let the client know when their link has disconnected without requiring the client to set up a new method for the server to call?
  * Instead of waiting for an error to be returned if a device attempts to send a message without being linked I made a new ServerData request that clients can post that'll return whether or not they're currently linked.
